# 6. 探针：读得出，就用到了吗

设我们收集了模型某一层的激活，并为每个样本标出“是否包含复数名词”。如果一个小分类器能从激活预测这个标签，我们发现了什么？

本章将这个小分类器称为**探针**（probe）。我们先学会训练和评估它，再把“可解码”与“参与模型计算”分开。

## 6.1 冻结模型，再训练读出器

对于样本 $i$，设激活为 $h_i\in\mathbb R^d$，标签 $y_i\in\{0,1\}$。线性探针计算：

$$p(y_i=1\mid h_i)=\sigma(h_iw+b),\qquad \sigma(z)=\frac1{1+e^{-z}}.$$

训练时冻结被研究模型，只更新 $w,b$。使用二元交叉熵拟合标签，然后在未用于训练的样本上报告准确率等指标。

冻结原模型很重要。如果把模型也一起训练，实验就不再是“原来的激活里有什么信息”，而是“经过适配后能学会什么”。

## 6.2 一个完全可检查的合成实验

我们生成相互独立的信号 $s$、干扰变量 $z$ 和噪声 $\epsilon$，令隐藏状态为 $h=(s,z,\epsilon)$。下游分类器只使用 $s$：

$$f(h)=\mathbf1[s>0].$$

现在训练探针预测 $z$ 的正负。因为 $z$ 就在隐藏状态第二维，线性探针能够读出它。然而，把第二维清零不会改变 $f$ 的输出。这正是第二章思想的多样本版本。

运行：

```bash
python -m experiments.probes
```

程序划分独立的训练集和测试集，并比较正常标签与随机标签控制。核心训练代码如下：

```python
probe = torch.nn.Linear(3, 1)
optimizer = torch.optim.Adam(probe.parameters(), lr=0.05)
for _ in range(200):
    logits = probe(h_train).squeeze(-1)
    loss = torch.nn.functional.binary_cross_entropy_with_logits(logits, y_train)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

这里 `h_train` 和 `y_train` 由完整脚本构造；代码片段突出探针与目标网络分离的训练方式。合成实验的好处是我们知道真实下游规则，不必猜测。

## 6.3 为什么需要训练集之外的测试

一个容量很大的探针可能记住样本。如果同一个实体、模板或文档同时出现在训练集和测试集，它也可能利用重复信息，让分数看起来很好。

因此应按问题选择划分单位。例如研究语法时，可以按模板划分；研究实体属性时，可把一部分实体完全留给测试集。随机按句子切分不总是足够。

至少比较：多数类基线、正常标签探针、随机标签或其他合适的控制任务。模型选择应在训练集和验证集完成，最后才报告测试集结果。随机标签控制只是一个起点，不能排除所有词汇记忆或数据泄漏。

## 6.4 线性不等于简单语义

线性探针限制了读出器的形式，这比无限制的大网络更容易分析。但一个方向可能混合多个因素。探针能识别情感，可能部分利用感叹号、长度或主题；这与它发现了“纯粹的情感变量”并不是一回事。

我们还应控制混杂因素：把句子长度匹配、更换主题、构造语义相反但词汇相近的样本。解释标签的定义和数据来源，往往比多加一个小数点更重要。

## 6.5 从读出走向干预

如果想进一步检验模型是否使用某个方向，可以尝试改变该方向上的分量，再看原任务输出。但仍要谨慎：探针的读取方向不必等于一个“只改变目标概念”的写入方向；投影删除也可能同时损害其他信息。

在我们的合成实验里，删除第二坐标有明确含义，因为我们知道数据生成规则。真实激活中的坐标未必如此干净。概念擦除和子空间干预因此需要独立评估其副作用。

::: warning 这个方法会怎样误导我们
高测试准确率支持“在这个分布、这个标签定义和这个读出器下，信息可解码”。它不证明模型原本使用该信息，也不证明找到了唯一语义方向。低准确率则可能来自信息非线性编码、样本不足或训练失败，不能直接证明信息不存在。
:::

## 小结

探针是一种读取工具。它需要明确标签、冻结目标模型、恰当的数据划分与控制任务。把“可解码”作为清楚但有限的结论，才能知道下一次干预实验还需要回答什么。

## 练习

1. **基础**：在合成实验中，预测 $s$ 与预测 $z$ 的探针都可能很准确。为什么两者对下游任务的意义不同？
2. **基础**：把正常标签随机打乱，分别观察训练和测试准确率。
3. **进阶**：为情感探针设计一个按主题划分的测试，说明它能排除哪种捷径、不能排除哪种捷径。
