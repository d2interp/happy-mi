# 8. 归纳头：一个复制算法

给模型一段随机序列，再重复其中一部分：`A B C D A`。如果下一项是前面出现过的后继，它应该预测 B。这里不需要理解 A、B 的语义，只需要发现“上次 A 后面接了什么”。

归纳头（induction head）是机制可解释性中的经典案例。本章先描述算法，再理解两个注意力头怎样合作。我们会明确区分算法演示与对训练模型的实验证据。

## 8.1 规则是怎样的

归纳复制模式通常写为：

$$[A][B]\ldots[A]\longrightarrow[B].$$

当前 A 应当从前一次 A 的后继位置读取 B。注意，这与“看到 A 就输出训练语料中最常见的 B”不同。这里的 A→B 对应关系来自当前上下文，可以每次重新随机生成。

为了区分上下文复制与固定记忆，可以用随机 token 序列测试，而不是只用熟悉的短语。还应检查重复、模糊后继和没有匹配项时的行为。

## 8.2 为什么只匹配当前 token 还不够

在第二个 A 处，直接找与 A 相同的键，会找到第一个 A；但我们需要的内容是它后面的 B。于是，一个有用的中间步骤是：让 B 所在位置携带“我的前一个 token 是 A”的信息。

这可以由前一层的 **previous-token head** 完成：每个位置读取自己前一个位置的信息，并写入残差流。B 的位置因此同时含有 B 自身的信息和“前一个是 A”的信息。

下一层的头用当前 A 作为查询，与各位置携带的“前一个 token”信息匹配。它就可以选中 B 的位置，再通过 OV 路径复制 B 的信息。

## 8.3 用一个位置表把过程算清楚

| 位置 | 当前 token | 可供后层读取的前一个 token |
| --- | --- | --- |
| 0 | A | 无 |
| 1 | B | A |
| 2 | C | B |
| 3 | D | C |
| 4 | A | D |

在位置 4，查询匹配 A，候选键来自上表第三列，于是选中位置 1。值路径再从位置 1 读取 B。这展示了“前一头写入的信息改变后一头的键”的组合方式，常称为 K-composition。

这个表是理想化算法。实际模型使用连续向量、softmax 和多个头，可能只近似实现此规则。

## 8.4 动手验证复制规则

下面的代码实现离散规则，特意不把它包装成训练模型：

```python
tokens = ['A', 'B', 'C', 'D', 'A']
current = tokens[-1]
source_positions = [j for j in range(1, len(tokens))
                    if tokens[j - 1] == current]
prediction = tokens[source_positions[-1]] if source_positions else None
print(prediction)  # B
```

选最后一次匹配是这个教学规则的人为约定。真实头在多个匹配位置之间如何分配注意力，需要测量，不能由代码替它决定。

运行 `python -m experiments.induction` 可以同时查看“按前一 token 匹配的矩阵”与预测。在经典序列中，末行的读取位置应当指向 B，而不是前一个 A。

## 8.5 怎样在训练模型上寻找证据

先确认随机重复序列的后半段预测损失降低；再寻找在重复 token 的后继位置上分配注意力的头。但这两步还不够，我们还想知道头是否真的复制了源位置内容，以及干预它是否影响重复序列的预测。

可以分别测试读取模式、OV 的复制倾向、头消融效应，以及前一层相关头对后一层键的影响。不同测试回答不同问题；某个头的一张漂亮图只满足其中很少一部分。

原始研究在 attention-only 小模型中提供了特别清楚的机制分析，并讨论了更复杂模型中的证据。不要把小模型上的完整解释直接推广成“所有上下文学习都由归纳头实现”。

::: warning 这个方法会怎样误导我们
重复序列上的性能提升还可能与其他模式有关。一个头可能具有 induction-like 注意力，却不进行有效复制；也可能参与更复杂的功能。归纳头是一个具体的局部算法案例，不是上下文学习的唯一理论。
:::

## 小结

归纳复制需要把“匹配什么”和“复制什么”分开。前一层提供前驱信息，后一层利用它找到后继内容，是理解头组合的好入口。真正的研究要从算法可能性继续走向权重、激活和干预证据。

## 练习

1. **基础**：对 `P Q R P`，写出读取位置与预测 token。
2. **基础**：对 `A B A C A`，规则有哪些候选后继？为什么不能直接假定模型一定输出 C？
3. **进阶**：设计一个数据集，区分固定 A→B 记忆与利用当前上下文复制。
