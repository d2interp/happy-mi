# 9. IOI：从组件到回路

在句子“When Mary and John went to the store, John gave a drink to”中，两个名字都出现过，John 还出现了两次。模型要继续生成 Mary，需要利用名字在句子中的角色，而不只是选择出现次数最多的名字。

间接宾语识别（indirect object identification，IOI）研究的就是这一类任务。它是把语言模型的一项行为连接到多个内部组件的经典案例。本章重点是理解证据怎样组合，不要求记住论文中的每个头编号。

## 9.1 把自然语言任务变成可测量问题

我们把被赠予东西的人称为 IO，把执行赠予动作的人称为 S。上例中 Mary 是 IO，John 是 S。测量指标可以是最后位置的 logit 差：

$$m=\ell_{\mathrm{IO}}-\ell_{\mathrm{S}}.$$

正值说明模型在这两个候选之间更偏向 IO。这不保证 IO 是整个词表里的最高分答案；两候选比较与完整生成质量要分开报告。

任务数据通常使用多个模板、名字和词序安排。只研究一句话，很难区分模型利用的是角色信息还是特定字符串。训练或发现回路用的模板与评估模板也应尽可能分开。

## 9.2 一个机制层面的概述

原始 IOI 研究在 GPT-2 small 中识别了协作的注意力头类别。可以先把主要思路理解为：识别名字与重复出现的信息，抑制把主语名字作为答案复制的倾向，再把合适名字的信息写向输出。

其中 **name mover heads** 的作用与从名字位置读取、提高相应名字 logits 有关。**S-inhibition heads** 会影响 name mover 的读取，使它们减少对主语名字的关注。更早的头提供重复 token、位置等相关信息。

这只是帮助入门的概述。完整回路包含备份和负向贡献等结构，不是每个组件都在独立地“理解一个语法概念”。头的功能名称是研究者对证据的概括，不是模型里预先存在的标签。

## 9.3 为什么需要多种证据

假设一个头关注 IO 名字，并提高 IO 的 logit。我们获得了读取与写入的观察。接下来还要检查：替换其输出是否影响指标；干预上游头是否改变它的注意力；这些效应是否在新名字和新模板上出现。

路径修补能够帮助区分“上游头通过 name mover 影响结果”与“上游头从另一条路径直接影响输出”。一次节点消融往往混合了这两种效应。

合理的研究过程不是看到一个名字相关的注意力头就结束，而是持续比较候选计算图与干预结果。

## 9.4 怎样评价一个回路

**忠实性（faithfulness）**问：在约定的替换基线和任务指标下，保留这组回路能在多大程度上重现完整模型的行为？

**完备性（completeness）**关心：是否遗漏了重要的相关机制，尤其是在进一步干预时，所选回路能否解释完整模型的变化？仅仅在原始输入上复现分数，并不能排除备份路径。

**最小性（minimality）**问：选进来的组件是否有必要保留？删除某个组件是否会在某些合适的测试条件下损害回路表现？简单的逐一删除也可能受冗余影响，不能证明找到了唯一最小解释。

这些标准需要操作化：你使用哪类干预、哪组数据、哪种指标？不同定义可能给出不同的回路。原论文的具体测试方式应与它的结论一起阅读。

## 9.5 本书的 GPT-2 实验做到哪一步

[配套实验](../labs/gpt2.md)使用真实 GPT-2 权重，检查多个名字对，并在 block 输出处替换最后位置的残差向量。它能够让你看到：某些层的内部状态变化会影响 IOI 风格输入上的候选分数。

它没有重新识别原论文的完整头级回路，没有做路径修补，也没有证明所有语法形式都成立。把这个实验称为“IOI 风格的残差修补练习”是准确的；称为“完整复现 IOI 回路”则不准确。

建议先用少量句子调通流程，再扩展名字与模板；保存每对句子的原始分数，避免只保留支持预期的例子。调试集上的发现需要在独立测试集验证。

::: warning 这个方法会怎样误导我们
把某些头删掉后，其他头可能承担相似功能；某个名字可能由于词频或分词而产生特殊效应。GPT-2 的头编号是模型特定的，不适合作为跨模型的“语法器官编号”。结论的边界应包含权重版本、模板、名字分布和干预方式。
:::

## 小结

IOI 展示了从单个组件走向协作回路的研究方式。它的价值不仅在于发现了哪些头，更在于如何把功能假设、路径证据和回路评估联系起来。你自己的小项目也可以沿用这种证据组织方式。

## 练习

1. **基础**：为什么“John 出现更多次”不足以解释模型选择 Mary？
2. **基础**：如果一组头能重现原始分数，是否说明不存在未发现的备份头？
3. **进阶**：设计两个新模板，一个保留 IOI 结构，一个破坏结构，说明它们分别能检验什么。
