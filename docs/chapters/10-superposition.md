# 10. 叠加：特征多于维度

如果网络只有两个隐藏坐标，最多能表示两个有用的特征吗？如果这些特征很少同时出现，答案可能没有这么简单。

本章通过一个训练的压缩小模型理解**叠加**（superposition）。重点是几何和数据分布，不是给每个神经元硬配一个含义。

## 10.1 特征不等于坐标轴

先区分三个词。**神经元**通常指架构中的一个坐标；**特征**指我们希望描述的数据属性或计算变量；**方向**是表示空间中的一个几何对象。

一个特征可以沿着多个坐标共同变化。即使特征数没有超过维度，一个坐标也可能混合多个特征。这种分布式表示不一定是叠加。我们在本章关注的是：多于隐藏维度的特征，是否能借助非正交方向共享空间。

“某神经元对多个语义模式激活”的多义性现象，与这种容量意义上的叠加有关，但两者不能直接画等号。

## 10.2 从三个方向挤进二维开始

二维平面上可以放很多方向，但不可能让三个非零方向彼此正交。若三个特征沿三个不同方向写入，同一时刻激活多个特征时就会相互干扰。

设输入 $x\in\mathbb R^n$，编码矩阵 $W\in\mathbb R^{n\times d}$，且 $n>d$。压缩状态为 $h=xW$，重构为：

$$\hat x=\operatorname{ReLU}(hW^\top+b).$$

展开第 $i$ 个重构坐标：

$$\hat x_i=\operatorname{ReLU}\left(x_i\|w_i\|_2^2+\sum_{j\ne i}x_j(w_j\cdot w_i)+b_i\right).$$

第一项是特征自身信号，求和部分是其他特征的干扰。ReLU 和偏置可以滤除一部分干扰，但不能无条件地解决所有冲突。

## 10.3 稀疏数据为什么有帮助

我们令每个特征以概率 $p$ 非零，非零幅度从 $[0,1]$ 随机采样。较小的 $p$ 意味着稀疏：每个样本只有少数特征活跃。

当很多特征很少共同出现时，方向不正交造成的冲突更少被触发。模型可以在压缩容量与干扰代价之间折中。重要的是特征的共同激活分布，而不是“稀疏一定更可解释”这句口号。

损失为加权重构误差：

$$\mathcal L=\mathbb E_x\sum_i I_i(x_i-\hat x_i)^2.$$

其中 $I_i$ 是人为设定的特征重要性。它影响模型愿意牺牲哪些特征。基础实验用相同重要性，以减少额外因素。

## 10.4 训练五个特征、两个隐藏维度

运行：

```bash
python -m experiments.superposition
```

程序在多个稀疏度下训练 $n=5,d=2$ 的模型，记录独立测试数据的误差、权重范数与特征方向的余弦矩阵。基础模型的核心计算是：

```python
h = x @ W
x_hat = torch.relu(h @ W.T + bias)
loss = ((x_hat - x) ** 2).sum(dim=-1).mean()
```

训练后不要只看总损失。随着 $p$ 变小，输入大多为零，即使永远预测零，均方误差也会降低。应同时与**零输出基线**比较，并查看活跃特征的误差、每个方向的范数和干扰结构。

![固定种子训练后，五个输入特征在二维瓶颈中的权重方向；三个面板分别对应非零概率 0.5、0.1、0.03。](/results/superposition.svg)

这是配套脚本的实际输出。箭头编号对应五个输入特征；在这次训练中，更稀疏的两组出现了五个较清晰的方向。完整误差与零基线见[实测记录](../labs/results.md)。图只是一次训练的结果，下一步应更换种子、查看未活跃特征的误差并检验替代解释。

可以把 $W$ 的五行画成平面上的五支箭头。若多于两个特征拥有明显非零的表示方向，且重构优于零基线，就得到这个设定中共享低维空间的证据。漂亮的多边形不是必须出现的验收标准，有限训练与随机种子会影响几何。

## 10.5 这个实验怎样帮助理解语言模型

它提供一种解释：神经元看起来多义，可能是因为有用的变量沿着共享空间中的方向表示。于是只观察单个神经元未必是最有效的分析方式。

但这个小模型的真实特征由我们定义，训练目标也是重构这些特征；语言模型的任务与数据更复杂。小模型证明的是一种机制的可能性，并帮助我们构造假设，不是直接测量了某个大模型的真实特征数。

::: warning 这个方法会怎样误导我们
总误差降低可能只是数据更稀疏；一个神经元多义可能只是坐标旋转；方向图的对称形状也可能依赖超参数。报告这些结果时应包含数据生成规则、基线、种子和训练预算。
:::

## 小结

隐藏维度限制线性独立方向的数量，但在稀疏数据与非线性解码条件下，网络可能用非正交方向表示更多特征。叠加带来容量，也带来干扰；下一章研究如何从激活中学习一组更容易分析的方向。

## 练习

1. **基础**：二维平面中最多有几个两两正交的非零方向？这与可以画多少支箭头有什么不同？
2. **基础**：将非零概率从 0.5 降为 0.05，为什么必须同时报告零基线误差？
3. **进阶**：把两个特征设为总是共同激活，预测它们学到的几何会如何变化，再修改生成器测试。
