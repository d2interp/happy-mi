# 11. 稀疏自编码器

如果原始激活中的坐标混合了多个特征，我们能不能学出一套更容易分析的坐标？**稀疏自编码器**（sparse autoencoder，SAE）是解决这一问题的一类工具。

本章只学习最基本的 ReLU-L1 SAE，理解重构与稀疏性的折中。基础目标是会训练、会评价、知道不能从结果里推出什么。

## 11.1 把激活写成少量方向之和

给定一个 $d$ 维激活 $h$，我们希望近似表示为若干字典方向的加权和：

$$\hat h=\sum_{j=1}^{m}z_jd_j+b_d,\qquad m>d.$$

字典可以有很多方向，但每个样本只使用少量非零系数 $z_j$。这与上一章的压缩方向相反：上一章从已知特征压缩到低维；这里从低维激活中推断一个更宽但稀疏的编码。

令 $W_d\in\mathbb R^{m\times d}$ 的行是字典方向，编码器为：

$$z=\operatorname{ReLU}((h-b_d)W_e+b_e),\qquad \hat h=zW_d+b_d.$$

$W_e\in\mathbb R^{d\times m}$ 负责推断系数，$W_d$ 负责重构。除非实现明确绑权，两者不要求互为转置。

## 11.2 两个目标为什么会冲突

最基本的损失为：

$$\mathcal L=\mathbb E_h\left[\|h-\hat h\|_2^2+\lambda\|z\|_1\right].$$

第一项希望保存信息，第二项鼓励更少、更小的激活。$\lambda$ 太小时编码可能很稠密；太大时模型可能丢掉有用信息。

还要控制字典方向的尺度。否则把 $W_d$ 放大、把 $z$ 缩小，就可能保持重构不变而减少 L1 惩罚。基础实验在每次更新后把字典行归一化为单位长度，避免这一缩放捷径。

L1 惩罚也会压低系数幅度，这常称为 shrinkage。它是我们理解其他 SAE 变体的起点，而不是应该在教程里隐藏的细节。

## 11.3 在已知字典上做实验

为了能检查答案，我们先随机生成一个真实字典 $D_*$，再用稀疏非负系数 $z_*$ 产生激活：

$$h=z_*D_*.$$

训练 SAE 时只给它 $h$，不把真实系数和字典交给它。训练结束后，我们才比较学习到的字典与真实字典。

```bash
python -m experiments.sae
```

实验对多个 $\lambda$ 训练模型，报告测试集上的重构误差、平均非零数、死隐元数和方向匹配分数。它使用固定种子和独立测试样本；不是在 GPT-2 上训练的 SAE，不能把其中的合成方向称为语言概念。

## 11.4 至少看四类指标

**重构误差**衡量保留了多少输入激活；与用训练集均值预测测试激活的基线比较，避免只看绝对数字。

**稀疏度 $L_0$**是每个样本中非零系数的数量，通常报告其均值。它与损失中的 L1 范数不同。

**死隐元**指在评估数据上从未超过指定阈值的编码坐标。阈值和数据量影响这个定义；“没有激活过”不代表在任何输入上都永远不会激活。

**方向恢复**在合成实验中可以用真实方向与学习方向的余弦相似度衡量。简单的逐个取最大匹配允许多个真实方向匹配同一隐元，因此只是诊断，不等于严格的一一字典恢复证明。

在语言模型上，还要评价用重构激活替换原激活后的输出变化。很小的平均 MSE 也可能损害一个对任务关键的方向；重构质量与行为保真度是两种指标。

## 11.5 给隐元解释之前，先找反例

假设一个隐元在很多城市名称附近激活。我们可以猜测它与地名有关，但还要检查城市以外的地点、同名人物、虚构地名以及没有地名的句子。

只查看最高激活样本容易确认自己的猜测。更好的做法是写下候选解释，收集支持样本和反例，并在未用于命名的样本上评估。进一步干预该隐元时，还要区分沿字典方向加值的效果与原模型实际依赖这一特征的证据。

## 11.6 其他变体放在哪里

TopK 直接限制每个样本保留的编码数量；JumpReLU 使用带阈值的激活函数。这些方法缓解了某些训练和稀疏性控制问题，但没有自动解决语义唯一性。

基础篇先掌握一套可运行的 ReLU-L1 实验。准备深入时，再读变体论文并在相同数据和评价指标下比较，而不是只比较展示出来的几个漂亮隐元。

::: warning 这个方法会怎样误导我们
SAE 可以把一个概念拆到多个隐元，也可能把多个概念混在一起；换字典宽度、稀疏度或种子，结果可能变化。训练目标约束的是重构与稀疏性，并没有直接规定“每个隐元等于一个人类概念”。
:::

## 小结

SAE 为激活提供一个可学习的稀疏字典。它是分析工具，其输出需要独立评价。合成数据能帮助我们检查方法，真实模型上则还要检验行为保持、解释泛化与干预副作用。

## 练习

1. **基础**：为什么放大解码器、缩小系数会使没有尺度约束的 L1 目标出现问题？
2. **基础**：如果重构误差很好，但平均 $L_0$ 接近字典宽度，这还是一个好的稀疏解释吗？
3. **进阶**：改变字典宽度和随机种子，比较高匹配方向是否稳定；说明为什么只比较重构误差不够。
