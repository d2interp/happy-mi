# 关于 Happy MI

Happy MI：动手学机制可解释性，是 d2interp 社区维护的中文教程。我们希望读者能够亲手观察神经网络的计算，并对自己的解释提出可检验的预测。

基础篇以经典、可教学的方法为主。研究材料比当前正文更广，但我们不把所有新论文都放进必修目录。首版是 v0.1，欢迎研究者、教师和第一次接触 MI 的读者一起审阅。

## 参考与致谢

- [Dive into Deep Learning](https://d2l.ai/)：文字、数学与代码相互配合的教材组织方式。
- [Happy LLM](https://github.com/datawhalechina/happy-llm)：中文入门教程的阅读与社区协作体验。
- [Learn Mechanistic Interpretability](https://github.com/FlyingPumba/learn-mech-interp)：主题导航与可解释性知识组织。
- [Neel Nanda 的 Quickstart](https://www.neelnanda.io/mechanistic-interpretability/quickstart-old)：从具体问题和小实验开始的学习建议。
- [Transformer Circuits](https://transformer-circuits.pub/) 与各章引用的论文作者：本教程的重要学术来源。

本书正文和示例代码独立编写；学术论断尽可能指向一手材料。

## 参与贡献

仓库：[d2interp/happy-mi](https://github.com/d2interp/happy-mi)。发现错误时，请说明章节、原句、修改建议与依据。报告实验问题时，附依赖版本、命令、种子与完整报错。

我们尤其欢迎三类反馈：一个初学者读不懂的过渡；一个需要更明确适用条件的结论；一段无法按说明运行的代码。新增方法须说明为什么适合基础教程，以及它依赖的先修内容。详细规范见仓库 `CONTRIBUTING.md`。

## 版本与勘误

v0.1 为基础篇初版。代码自动检查不能代替科学审阅，实验正常运行也不意味着结论自动成立。经确认的勘误直接修订正文，并在 Git 历史中保留变更；较大的教学或方法调整记录在 `CHANGELOG.md`。
