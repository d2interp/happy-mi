# 从这里开始

欢迎来到 Happy MI。这本教程围绕一个问题展开：**神经网络是通过什么内部计算得到答案的？** 我们把这样的研究称为机制可解释性（mechanistic interpretability，MI）。

你不需要已经读过可解释性论文。前两章从一个只有两个中间节点的模型出发，不需要安装软件；第三章补上向量、矩阵、导数和张量操作。读到 Transformer 时，我们再解释它与语言预测的关系。

## 你需要哪些基础

如果你会 Python 的变量、列表、循环和函数，可以直接开始。完全没有编程经验也可以先读前两章、操作网页实验，再读第三章的代码入门。运行第六章之后的训练实验，需要理解函数、数组索引和基本的 PyTorch；不要求事先会训练大模型。

“零基础”在这里意味着不需要机制可解释性基础，也提供数学和编程的过渡；它不意味着能跳过所有练习。遇到一个张量乘法时，写下它的形状，常常比再读一遍概念更有效。

## 怎样使用一章

先读开头的问题，并在看结果前写下预测。正文把直觉、公式和小例子放在一起；不熟悉的符号可以查[术语表](../reference/glossary.md)。做完实验后，认真读“这个方法会怎样误导我们”，然后完成一两道练习。练习标有基础或进阶，答案集中在[习题提示](../reference/answers.md)。

你会接触三种实验，必须区分它们的结论范围。

| 类型 | 本书例子 | 能说明什么 |
| --- | --- | --- |
| 手工构造 | 双节点网络、归纳复制示意 | 方法的定义、逻辑反例、算法的可能性 |
| 训练小模型 | 稀疏数据压缩、合成字典 SAE | 在已知数据生成机制下，训练和解释的表现 |
| 预训练模型 | GPT-2 残差修补 | 在指定输入和指标下，真实模型的干预效应 |

手工构造出一个回路，并不能证明 GPT-2 学到了同一个回路。复现一个模型上的结果，也不能自动推广到所有大模型。

## 这版教程的范围

基础篇 v0.1 选择经典方法，重点讲清它们回答什么问题、依赖哪些假设。它包含可运行的教学实验与原论文导读，但不是对每篇论文全部结果的复现。网站、实验和文字会继续接受审阅；遇到错误欢迎通过页面底部的“改进这一页”或 GitHub Issue 提交勘误。

从一个小问题开始、运行现成实验、按需补知识的节奏，受到 [Neel Nanda 的 Quickstart](https://www.neelnanda.io/mechanistic-interpretability/quickstart-old) 启发。那篇文章是历史入门指南；本书的安装方式以[环境准备](./setup.md)为准。
