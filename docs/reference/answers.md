# 习题提示与参考答案

先独立完成，再展开对应章节。开放题没有唯一答案；重点看实验是否能区分相互竞争的解释。

## 第 1 章

::: details 展开答案
1. 行为结论需要独立样本上的输出评估；可读出需要训练读出器并在独立数据上测试；参与判断需要设计干预与对照，并说明结论范围。
2. 固定输入为 1，分别置零两个节点，比较分数。只置零第二个节点不会改变输出。
3. 可研究“模型在这些主谓一致模板中是否偏好正确的单复数动词”。指定候选 logit 差、句长控制和新模板测试，比“理解语法”更可操作。
:::

## 第 2 章

::: details 展开答案
1. 两个节点原本都是零，干预没有改变值。
2. 第二个节点成为输出来源，消融效应随之交换。
3. OR 模型的参考状态为 (1,1) 时，两个单独消融均输出 1，联合消融输出 0。单独无效不能排除参与或冗余。
:::

## 第 3 章

::: details 展开答案
1. 结果是 [4,6]。
2. 分别是 (4,8) 和 (6,8)。后者平均 batch 轴，而不是取最后 token。

:::

## 第 4 章

::: details 展开答案
1. $QK^\top$ 和 $A$ 都是 $6\times6$；$W_{OV}$ 是 $32\times32$，其秩不超过头宽度 8。
2. 因果掩码禁止第一个位置读取未来，唯一可读位置是自己。
3. 注意力分布只由 QK 与掩码决定；输出投影为零时，写入为零，图上仍可有清楚模式。
:::

## 第 5 章

::: details 展开答案
1. `detach` 避免保留梯度图，`clone` 避免缓存与原张量共享可被修改的数据。
2. 新的第二项为 −1，总分数差为 1。
3. 例如早期写入 $a$，后层再计算 $-a$。原运行中早期直接项非零，但删除早期项也改变了后层计算。实际消融效应不能仅从原直接项推出。
:::

## 第 6 章

::: details 展开答案
1. 下游规则只依赖 $s$；$z$ 可读出但未被使用。
2. 线性读出器对独立随机标签通常难以泛化。训练表现也受样本数和容量影响；不要假定每次恰好为 50%。
3. 在若干主题训练、完全不同主题测试，可检验主题捷径的部分影响；仍不能自动排除标点、长度等其他因素。
:::

2. 原状态放回原位置应保持计算不变，可以暴露 hook 错误、缓存污染、dropout 和位置错配。
3. 不能。OR 网络中两个单独修补都可恢复输出，联合效果却不相加；非线性和共同路径会产生交互。
:::

## 第 8 章

::: details 展开答案
1. 最后 P 匹配位置 1 的前驱 P，读取 Q。
2. 后继候选是 B 和 C；选择最后一次匹配只是教学代码约定，真实注意力可能分散或有其他偏好。
3. 每个样本重新随机分配 token 对应关系，并在同一输入里提供一次 A B 后再出现 A；保持 token 频率对照，避免固定共现解释。
:::

1. 频次捷径倾向 John，角色判断却支持 Mary；还需要跨模板、跨名字检验，不能靠一个例子排除全部词汇偏好。

3. 保留赠予关系但更换场景可测试模板泛化；让两个名字指向同一角色或改变句法关系可检查原有机制假设的范围。说明预期答案与 token 对齐。
:::

## 第 10 章

::: details 展开答案
1. 最多两个。可以画无限多方向，但三个以上方向无法全部两两正交。
2. 更稀疏的数据更接近零，零预测本身也会改善；需要相对误差与活跃特征误差。
3. 总共同激活的特征可能共享更相近方向，但训练结果依赖目标、其他特征和模型容量。先记录预测，再比较种子。
:::

## 第 11 章

::: details 展开答案
1. 重构项可保持不变而稀疏惩罚下降，因此需要控制解码器范数或使用尺度相关的惩罚。
2. 这只是一个重构良好的稠密编码；应联合评价稀疏性与解释用途，不能仅凭低误差称成功。
3. 低误差可能对应很多不同字典；跨种子比较应注意排列、特征分裂和多对一匹配，不能直接比较隐元编号。
:::

## 第 12 章

::: details 展开答案
1. 合格计划包含输入、指标、假设、预测、对照与结论边界。
2. 常见泄漏是用最终测试集选择层、超参数或最漂亮的图；将选择过程移到发现集和验证集。
3. 重点补齐缓存位置、分词、版本、原始数据与失败案例。让别人提出问题，本身就是检查报告完整性的实验。
:::
