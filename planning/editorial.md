# 基础篇编辑决策

本文件记录首版范围，供后续作者延续，不作为读者的先修要求。

- 书名：Happy MI：动手学机制可解释性；仓库 d2interp/happy-mi。
- 面向机制可解释性零基础读者。编程零基础也能阅读前两章；执行完整实验前补第三章 Python / 张量预备。
- 原调研的 27 章为素材库，基础篇压缩为 12 章。各章保留问题、推导、实验或纸笔活动、失效模式、练习、一手文献。
- 主线取 Transformer 基础、logit lens、线性探针、消融与 activation patching、归纳头、IOI、叠加、ReLU-L1 SAE。2025–2026 新方法不进入必修路径。
- 网站采用 VitePress 1.6 的静态输出、本地搜索和构建期公式。相对调研建议的 Quarto，这版优先保障在线阅读与交互；实验为独立 Python / Notebook，不在网页构建时训练模型。
- 实验分三类：手工构造机制、训练的合成小模型、预训练 GPT-2。明确区分演示、复现和对真实模型的推断。
- 不将教程试运行称为论文复现；不把 patching 效应等同于全局必要性或充分性；不把 SAE 隐元视为唯一真实特征。
- 不复制参考教程正文、图片和代码；引用一手论文，自行绘图和实现。
- 首版为 v0.1，持续接受技术审阅；不自称已完成同行评审。

## 页面设计

颜色：纸白 #ffffff、浅蓝灰 #f4f7fb、正文 #243247、主题蓝 #2359a8、实验橙 #aa531c。
字体：中文使用系统 PingFang SC / Noto Sans CJK SC；标题用相同字体增加字重；代码使用系统等宽字体。
布局：顶部导航，左侧分部目录，中间正文，右侧页内目录。正文左对齐，约 38 个汉字宽；移动端目录折叠。
首页的视觉中心是可以亲手消融的三节点模型，其余布局保持克制。
